TASKFLOW TASK MANAGER
=====================

Task Structure
--------------

Each task contains:

- Task ID
- Task Title
- Priority
- Status
- Due Date


Priority Levels
---------------

LOW
MEDIUM
HIGH


Task Status
-----------

TODO
IN_PROGRESS
COMPLETED


Due Date
--------

Due dates use the following format:

YYYY-MM-DD

Example:

2026-10-15


Priority Rules
--------------

1. Every task must have one priority.
2. Valid priorities are LOW, MEDIUM, and HIGH.
3. HIGH priority tasks should be handled before LOW priority tasks when required.


Status Rules
------------

1. Every task must have one status.
2. A new task starts with TODO status.
3. A task can move from TODO to IN_PROGRESS.
4. A completed task has COMPLETED status.


Due Date Rules
--------------

1. A task can have a due date.
2. Due dates must use YYYY-MM-DD format.
3. The due date should be displayed with the task.


Invalid Priority
----------------

If an invalid priority such as URGENT is provided,
the priority should be rejected.

Valid priorities are:

LOW
MEDIUM
HIGH


Example Tasks
-------------

Task ID: 1
Title: Complete Git Training
Priority: HIGH
Status: IN_PROGRESS
Due Date: 2026-10-10


Task ID: 2
Title: Create Project Documentation
Priority: MEDIUM
Status: TODO
Due Date: 2026-10-15


Task ID: 3
Title: Review Pull Request
Priority: LOW
Status: COMPLETED
Due Date: 2026-10-20
