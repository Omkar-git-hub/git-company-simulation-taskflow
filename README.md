# TaskFlow — Git Workflow Lab

A small sample project created to practice **Git and GitHub workflows in a real-world development style**.

## Purpose

This project is used to practice:

* Feature branches
* Commits
* Pull Requests
* Code reviews
* Merge conflicts
* Releases and tags
* Branch cleanup
* GitHub collaboration workflows

## Features

TaskFlow currently supports:

* Task priority
* Task status
* Task due dates
* Due date validation
* Basic test cases

## Git Workflow

The project follows:

```text
Issue
 ↓
Feature Branch
 ↓
Commits
 ↓
Pull Request
 ↓
Code Review
 ↓
Changes
 ↓
Merge
 ↓
Release
```
